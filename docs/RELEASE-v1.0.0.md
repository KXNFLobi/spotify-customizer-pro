Aplicativo portátil para personalização visual do Spotify via Spicetify.

## Baixar e usar

1. Baixe **Spotify-Customizer-Pro-1.0.0-portable-x64.exe** em Assets abaixo.
2. Salve em uma pasta e abra com dois cliques. Não precisa instalar Node.js, Electron ou Spicetify.
3. O Spotify desktop convencional precisa estar instalado e ter sido aberto ao menos uma vez.
4. Escolha um tema e clique em Aplicar no Spotify. Um backup é criado antes da aplicação.
5. Para desfazer, use Restaurar original no aplicativo.

Windows 10 22H2 / Windows 11 x64. Microsoft Store não é suportado neste projeto. A compatibilidade depende da versão do Spotify e é verificada pelo Spicetify.

## Estado da versão

Versão inicial para testes. O executável foi empacotado no Linux, o conteúdo do pacote foi conferido e 13 testes automatizados passaram. A execução no Windows e a aplicação em Spotify real ainda precisam de validação. O executável não é assinado digitalmente; não desative as proteções do Windows para executá-lo.

Perfis e backups ficam nos dados locais de cada usuário. Não são enviados neste download. O pacote inclui Spicetify 2.46.4 oficial, recursos, licença LGPL-2.1 e fonte correspondente. Os fontes do aplicativo também estão disponíveis no arquivo spotify-customizer-pro.zip.
